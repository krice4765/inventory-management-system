### 🚀 Quick Start Guide

1. **Open Excel File**
   - Navigate to: C:\Users\kuris\Documents\AIproject\gemini-cli-tutorial\Excel_VBA_FileSplitter\FileSplitter_Project.xlsm

### 🔧 Form Control Setup Steps

1. **Open VBA Editor** (Alt + F11)
2. **Double-click UserForm_Split** in Project Explorer
3. **Add controls from Toolbox:**
   - Right-click in form design area
   - Select control from toolbox
   - Draw control on form
   - Set Name property in Properties window (F4)
4. **Repeat for UserForm_Progress**
5. **Save the project** (Ctrl + S)

### ⚙️ Important Settings

**Before using the application:**
1. **Excel Macro Settings**
   - File → Options → Trust Center → Trust Center Settings
   - Macro Settings → Enable all macros (for development)
   - Check "Trust access to the VBA project object model"

2. **File Locations**
   - Input files: Any location accessible to Excel
   - Output folder: Must have write permissions

### 🧪 Testing the Application

**Basic Test:**
1. Run TestFileSplitter from Module_Main
2. Select a test file (recommend starting with small files)
3. Choose output folder
4. Set split size (e.g., 1 MB for testing)
5. Click "分割実行" (Execute Split)

**Expected Results:**
- Progress dialog appears
- Files are created with .part001, .part002, etc. extensions
- Success message displays when complete

### 🔍 Troubleshooting

**Form doesn't display:**
- Check that all required controls are added with correct Names

**Compilation errors:**
- Verify all control Names match exactly
- Check that all modules are properly added

**Runtime errors:**
- Ensure input file exists and is accessible
- Verify output folder has write permissions
- Check that split size is a valid number

**VBA components missing:**
- Re-run this setup script
- Ensure VBA project access is enabled in Excel settings
