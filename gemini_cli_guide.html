Gemini CLI ガイド

このドキュメントは、Gemini CLI (Command Line Interface) の使い方を理解し、効果的に活用するためのガイドです。

Gemini CLI とは？

Gemini CLI は、Google の Gemini モデルを搭載した対話型コマンドラインエージェントです。ソフトウェアエンジニアリングタスクを安全かつ効率的に実行できるように設計されています。コードの読み書き、ファイルの操作、シェルコマンドの実行など、様々なタスクを自然言語で指示することで実行できます。

基本的な使い方

Gemini CLI との対話は、通常のチャットのように自然言語で行います。CLI はあなたの指示を理解し、適切なツールを呼び出してタスクを実行します。

コマンドとツールの利用

Gemini CLI は、内部的に様々なツール（関数）を使用してタスクを実行します。例えば、ファイルの読み込みには read_file、ディレクトリのリスト表示には list_directory、シェルコマンドの実行には run_shell_command などがあります。

あなたはこれらのツール名を直接入力する必要はありません。CLI があなたの意図を解釈し、自動的に適切なツールを選択します。

重要な考慮事項

  • 絶対パスの使用: ファイルやディレクトリを指定する際は、常に絶対パスを使用してください。例えば、C:\Users\YourUser\project\file.txt のように指定します。
  • コンテキストの提供: CLI は現在の作業ディレクトリやファイル構造のコンテキストを理解しています。しかし、より複雑なタスクでは、関連するファイルの内容やプロジェクトの構造について追加の情報を提供すると、より正確な結果が得られます。
  • 安全な操作: CLI は、ファイルシステムを変更する可能性のあるコマンドを実行する前に、その目的と潜在的な影響について説明します。これにより、意図しない変更を防ぎ、安全に作業を進めることができます。
  • 日本語での対話: 日本語での指示も可能です。CLI は日本語を理解し、日本語で応答します。

よく使う操作例

ファイルの読み込み

特定のファイルの内容を読みたい場合。

C:\Users\kuris\Documents\AIproject\gemini-cli-tutorial\src\pages\index.tsx の内容を教えてください。

ディレクトリの内容表示

現在のディレクトリや特定のディレクトリ内のファイルとフォルダをリスト表示したい場合。

現在のディレクトリのファイルをリストしてください。
C:\Users\kuris\Documents\AIproject\gemini-cli-tutorial\Excel_VBA_FileSplitter\src の内容をリストしてください。

ファイルの作成・編集

新しいファイルを作成したり、既存のファイルを編集したりする場合。

新しいファイル test.txt を作成し、"Hello, Gemini!" と書き込んでください。
C:\Users\kuris\Documents\AIproject\gemini-cli-tutorial\test.txt の "Hello, Gemini!" を "Hello, World!" に変更してください。

シェルコマンドの実行

CLI から直接シェルコマンドを実行したい場合。

npm install を実行してください。
ls -l を実行してください。
注意: ファイルシステムを変更する可能性のあるシェルコマンドを実行する際は、CLI がそのコマンドの目的と影響を説明します。

コードの生成・修正

特定の機能を持つコードを生成したり、既存のコードのバグを修正したりする場合。

Pythonでフィボナッチ数列を計算する関数を書いてください。
src/utils.js の calculateSum 関数にバグがあるので修正してください。

困ったときは

  • エラーメッセージ: CLI からエラーメッセージが表示された場合は、その内容をよく読み、指示に従ってください。特にパスの指定ミスや権限の問題が多いです。
  • 不明な点: 何か不明な点があれば、遠慮なく質問してください。CLI はあなたの質問に答えることができます。
  • ヘルプコマンド: /help と入力すると、CLI のヘルプ情報を表示できます。
